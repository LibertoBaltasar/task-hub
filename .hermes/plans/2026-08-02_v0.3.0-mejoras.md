## ⚠️ Riesgos
- **Offline mode**: toca el Repository, puede romper la app si no se testea bien
- **Subtareas**: requiere migración de datos en Firestore (añadir campo `subtasks: array`)
- **FCM**: el envío de push requiere un backend que mande las notificaciones (Firebase Cloud Functions o un endpoint HTTP). Solo el cliente no basta.

## 🔍 Google Calendar — investigación
- Se necesita OAuth 2.0 (Google Sign-In)
- Actualmente la app usa auth anónima → conflicto
- Alternativa: el usuario pega un token manual, o se añade Google Sign-In como opción
- API: `POST https://www.googleapis.com/calendar/v3/calendars/primary/events`
- Conclusión preliminar: viable pero requiere migrar auth de anónimo a Google
